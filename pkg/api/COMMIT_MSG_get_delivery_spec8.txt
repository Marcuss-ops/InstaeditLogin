feat(velox): extend GET /internal/v1/deliveries/{id} to spec §8 wire shape

Extend the existing handleGetInternalDelivery (in pkg/api/velox_handlers.go)
to populate the canonical spec §8 fields on top of the legacy v0
fields. Per the user-requested path "routes/internal/deliveries_get.go"
the closest semantic match in this repo (per Go internal-visibility rule
+ the prior `deliveries_create.go` precedent) is to extend in-place;
the handler keeps its mount point at /internal/v1/deliveries/{id} but
the JSON body now returns the §8 wire shape alongside the legacy v0
fields for backward compat.
