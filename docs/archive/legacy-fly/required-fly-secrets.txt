# InstaEdit → Velox control JWT (Phase 1 BFF). The HS256 secret MUST be
# identical to Velox's INSTAEDIT_CONTROL_JWT_SECRET. The Velox-side
# runtime verifier (instaeditauth/verifier.go) enforces a minimum of
# 32 bytes; the matching InstaEdit validator
# (internal/config/config.go::validateVelox) enforces the same. Generate
# once with `openssl rand -hex 32` and push to BOTH Fly and the Velox
# master /etc/velox-server.env (anchored on the deploy/install-server.sh
# preflight + deploy/validate-master-env.sh check).
# Rotate by importing the new value to Fly AND replacing
# INSTAEDIT_CONTROL_JWT_SECRET on the Velox master in the SAME window;
# a partial rotation rejects every /api/v1/velox/* request with 401.
VELOX_CONTROL_JWT_SECRET
